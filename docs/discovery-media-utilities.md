## Transfer and backup tools

**rclone.** Noble's manual comes from 1.60.1+dfsg-3ubuntu0.24.04.6. Resolute's comes from 1.60.1+dfsg-4ubuntu3.2. Both describe global options in the combined manual. Each captured copy or sync reply explicitly directs the reader to `rclone help flags` for these, and the root route issues that fixed request. Local and remote paths and the transfer examples in the leaf narrative never become option declarations. The count form of `--verbose` permits use without an explicit level. **restic.** The Noble 0.16.4-2ubuntu0.24.04.3 and Resolute 0.18.1-3ubuntu1 manuals both include read concurrency. Resolute adds `--stdin-from-command` and `--skip-if-unchanged` relative to the Noble man page. The former makes the remaining program and its arguments a source of snapshot data. The latter suppresses an unchanged snapshot. Repeated verbosity or `--verbose=n` selects a level. The fixed response specifies a maximum of two. [Upstream backup guide for 0.18.1](https://github.com/restic/restic/blob/v0.18.1/doc/040_backup.rst) · [Noble restic-backup(1)](https://manpages.ubuntu.com/manpages/noble/man1/restic-backup.1.html) · [Resolute restic-backup(1)](https://manpages.ubuntu.com/manpages/resolute/man1/restic-backup.1.html)

**Borg.** Noble 1.2.8-1 and Resolute 1.4.4-3 distinguish a child command providing file content from a child providing a list of paths. Resolute's `--files-changed MODE` selects how to detect file changes during the backup. Its default is `ctime`. Examples below the declaration sections describe operations and provide no additional flag rows. ## VLC and ImageMagick

**VLC.** The Noble 3.0.20-3build6 and Resolute 3.0.23-1 package manuals have identical decompressed content. The manual refers to `--longhelp --advanced` for all options of installed modules. Discovery requests ordinary `--help`, so additional plugin documentation depends on a different request. Positive and negative spellings are selectable independently. The 3.0.23 parser treats short `-v` specially. Repeating it increases verbosity. The long `--verbose` takes an integer, although the help prints both in one declaration. [Upstream help generator](https://code.videolan.org/videolan/vlc/-/blob/3.0.23/src/config/help.c) · [Upstream argument parser](https://github.com/videolan/vlc/blob/3.0.23/src/config/cmdline.c) · [Noble vlc(1)](https://manpages.ubuntu.com/manpages/noble/man1/vlc.1.html) · [Resolute vlc(1)](https://manpages.ubuntu.com/manpages/resolute/man1/vlc.1.html)

**ImageMagick.** Noble's ImageMagick 6 manual belongs to imagemagick-6.q16 8:6.9.12.98+dfsg1-5.2build2. The plain Noble `convert(1)` page is supplied by GraphicsMagick. Resolute supplies ImageMagick 7.1.2-18 in 8:7.1.2.18+dfsg1-1. Its version-suffixed manuals identify the suite. The shared upstream option index covers multiple tools and versions. Each replay instead uses the invoked executable's fixed help. [Upstream option index](https://imagemagick.org/command-line-options/) · [Noble ImageMagick convert(1)](https://manpages.ubuntu.com/manpages/noble/man1/convert-im6.q16.1.html) · [Resolute ImageMagick suite](https://manpages.ubuntu.com/manpages/resolute/man1/ImageMagick-im7.q16.1.html) · [Resolute convert(1)](https://manpages.ubuntu.com/manpages/resolute/man1/convert-im7.q16.1.html)

The fixed help joins `-write-mask filename` and `-word-break type` on one physical line. Other long entries wrap the operand or explanation onto the next line. The option table establishes two operands for `-sparse-color method args` and `-limit type value`, and one geometry operand for `-brightness-contrast`. A missing-operand diagnostic alone cannot establish acceptance. Separate parser/operation checks on disposable one-pixel images showed both commands reject the printed `-view`. The modern `magick` command also rejected `-support` and `-perceptible`. The `convert` command accepted both. Both accepted `-word-break` and `-brightness-contrast`. These qualifications apply to the observed 7.1.2-18 binaries. ## yt-dlp and 7-Zip

**yt-dlp.** Noble 2024.04.09-1 and Resolute 2026.03.17-1 both document the three operands of `--replace-in-metadata`. The newer manual also describes `-t` / `--preset-alias PRESET`. Preset expansion recipes such as `-t mp3` and flags embedded in configuration examples cannot redefine either the flag or its operand. User-defined `--alias ALIASES OPTIONS` consumes two shell arguments. The independently inspected package registry has 394 exact spellings, including parser compatibility entries that the public option tables omit or label unsupported. A parser-only check resolved the manual's singular `--srt-lang` to the registered `--srt-langs` as an unambiguous abbreviation. Passing `--srt-lang en` set the subtitle language list to `['en']`. That specific documented abbreviation is searchable and selectable. No network request or media download was involved. [Upstream 2026.03.17 manual](https://github.com/yt-dlp/yt-dlp/blob/2026.03.17/README.md) · [Tagged option parser](https://github.com/yt-dlp/yt-dlp/blob/2026.03.17/yt_dlp/options.py) · [Noble yt-dlp(1)](https://manpages.ubuntu.com/manpages/noble/man1/yt-dlp.1.html) · [Resolute yt-dlp(1)](https://manpages.ubuntu.com/manpages/resolute/man1/yt-dlp.1.html)

**7-Zip.** Noble supplies 23.01+dfsg-11 and Resolute supplies 26.00+dfsg-1. Both clients print a shared command index followed by a switch grammar. The 26 generic root declarations include simple optional attached values such as `-bb[0-3]`, `-mmt[N]` and `-mx[N]`. More complex templates such as `-ao{a|s|t|u}`, `-o{Directory}` and include/exclude patterns belong to the reviewed command-specific grammar. The root reader never truncates these to different insertable tokens. The `--` delimiter controls parsing. Named commands, braces and wildcard templates do not constitute additional literal switches. Direct subcommand discovery for `x` issues no executable or manual request. The fallback uses the root title and its own source set.
