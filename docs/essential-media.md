## From the declaration to the terminal

Resolute prints `-c[:<stream_spec>] <codec>` in its per-stream table. The old generic parser rejected that entire spelling. With the native table recognized, the stored flag is `-c`, its operand is `<codec>`, and the optional selector stays in Details. The separate manual entry adds the input/output scope, precedence and stream-copy explanation. At 60×16 the terminal test searches for **without reencoding**, scrolls through the resulting Details, cancels, reopens and inserts the literal option before a quoted suffix. No bracketed placeholder becomes shell text. The harness refreshes a private discovery cache and opens Bash with an empty bundled-profile directory. [Native table and manual readers](../cli_help/media_help.py) · [Bash/tmux checks](../tests/test_essential_terminal.py) · [Resolute ffmpeg(1)](https://manpages.ubuntu.com/manpages/resolute/man1/ffmpeg.1.html)

A group of consecutive manual declarations can share one explanation. For example, both `-c` and `-codec` own the paragraph that follows them. Noble short help omits operands on several declarations, including `-filter_threads` and `-discard`. The native option table establishes which require values. Both versions of FFprobe print `-show_data_hash` without its required algorithm and `-show_log` without its required log level. Both also print an operand beside the boolean `-hide_banner`. Discovery reconciles these signatures before merging prose. [Noble ffmpeg(1)](https://manpages.ubuntu.com/manpages/noble/man1/ffmpeg.1.html) · [Noble ffprobe(1)](https://manpages.ubuntu.com/manpages/noble/man1/ffprobe.1.html) · [Resolute ffprobe(1)](https://manpages.ubuntu.com/manpages/resolute/man1/ffprobe.1.html) · [6.1.1 probe declarations](https://github.com/FFmpeg/FFmpeg/blob/n6.1.1/fftools/ffprobe.c) · [8.0.1 probe declarations](https://github.com/FFmpeg/FFmpeg/blob/n8.0.1/fftools/ffprobe.c)

The same AVOption spelling can occur under several components. Its Details group identical definitions by owner and retain distinct constraints when they differ. For example, `-probesize` takes an integer, has a default of 5,000,000 bytes in the input-format context and includes its displayed range. Indented symbolic values such as `ignidx` belong to the enclosing flag. The read-only list of available view IDs is exported state. The writable `-view_ids` selects the views to decode. ## Source limits and reproduction

The help topic alias `-?` is described on the help row. A bare question mark is a shell glob, so the menu offers the literal `-h` spelling. The Noble manuals still describe `-sbsf` and `-show_format_entry`, which are absent from their respective native option tables. The project has separate evidence for the supported FFmpeg `-bsf:s` spelling. Filtergraph parameters, writer options, preset-file contents, example pipelines and generated stream indices belong to their parent argument. Optional components depend on the client build. The earlier bundled inventory records a wider surface from explicit long/full requests and FFmpeg 9.1.
