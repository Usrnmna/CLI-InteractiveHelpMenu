## Fixed sources and provenance

`curl --help all` is the curl driver's complete fixed request. Each other route uses exactly `COMMAND --help` and a separate `man -P /bin/cat --no-hyphenation --no-justification -s 1:8 -- COMMAND` lookup. Names are the literal executables in the table. These requests take no pending arguments. The manifest stores response bytes, the documented invocation and operand counts. Its `manual_only` field lists selectable rows added by the second source, including aliases stated in prose. Primary option spellings and aliases were transcribed from the documentation columns and compared with generated profiles. Source headings, notes and macro syntax were checked separately.

- The original Ubuntu 24.04 captures for curl, Wget, rsync, jq and ripgrep record bounded, normalized excerpts. The five short matrix text files are hand-authored syntax specimens. For example, Wget’s installed excerpt includes `-T`, jq’s includes `--join-output`, and ripgrep’s installed spelling uses `--color=WHEN`. The Noble sandbox image lacked xz and the other five clients. The project independently retains complete Noble and Resolute rsync client responses. Both yield 195 literal spellings from help alone. ## Material source distinctions

- **curl and Wget.** curl’s dotted HTTP and TLS names are individual switches. `-#` and `-:` are literal aliases of `--progress-bar` and `--next`. The column in curl help labels a subject, but bare `--help` also works. Wget omits the operands of `--max-redirect` and `--hsts-file` in fixed help. The tagged parser requires a count and a filename. The deprecated `--html-extension` corresponds to `--adjust-extension`. Wget can also take a Metalink preferred location as a value when built with that feature. [curl manual](https://curl.se/docs/manpage.html) · [Wget 1.25 manual source](https://gitlab.com/gnuwget/wget/-/raw/v1.25.0/doc/wget.texi) · [Wget option table](https://gitlab.com/gnuwget/wget/-/raw/v1.25.0/src/main.c)
- **Conditional Wget declarations.** In the disposable Resolute client, `--bind-dns-address`, `--dns-servers`, `--input-metalink`, `--metalink-index`, `--metalink-over-http` and `--preferred-location` each produced an unrecognized-option diagnostic with a fixed version request. The manual-derived rows identify the c-ares or Metalink prerequisite. The same build accepted `--keep-badhash`, `--egd-file`, `--random-file`, `--no-follow-ftp` and `--no-ftps-resume-ssl` before `--version`. These checks establish argument parsing only. [Resolute wget(1)](https://manpages.ubuntu.com/manpages/resolute/man1/wget.1.html)
- **rsync.** `-@` takes a timestamp comparison window. `--cc=`, `--zc=` and `--zl=` inherit the corresponding choice/level operands. Only evidenced, real spellings of negations and compatibility switches enter the menu. The `--no-OPTION` template, private peer switches, popt alias examples and remote `-M--debug=…` payloads are excluded. The daemon section explicitly qualifies the meaning of `-M` and shared options. Both Ubuntu client captures report a build without creation-time support. The tagged parser and manual establish the independent spelling check. [3.4.1 parser](https://github.com/RsyncProject/rsync/blob/v3.4.1/options.c) · [3.4.1 manual](https://github.com/RsyncProject/rsync/blob/v3.4.1/rsync.1.md) · [Release comparison](rsync-manual-coverage.md)
- **jq and ripgrep.** The jq option section distinguishes `-f FILE` from two-word variable bindings. `--run-tests [filename]` must come last and otherwise reads standard input. `--binary` and `-b` affect newline conversion with native Windows jq. A command-line parser check rejected the configure-time `--disable-decnum`. Ripgrep’s declared inverse switches are identified from the positive option’s own description. `--maxdepth=` inherits a depth operand, `--no-encoding` restores automatic detection, and `-.` enables hidden-file searches. A configuration example containing `-j4` and find’s `--print0` are outside the menu. [jq 1.7 manual](https://jqlang.org/manual/v1.7/) · [jq 1.8 manual](https://jqlang.org/manual/v1.8/) · [ripgrep 15.1 option definitions](https://github.com/BurntSushi/ripgrep/blob/15.1.0/crates/core/flags/defs.rs)
- **GNU and uutils.** The GNU declarations can use one line for equivalent fixed-value modes and a separate line for another use of the same long option. Inferring one mandatory operand for every spelling blocks valid `sort -C FILE` and `du --time FILE` invocations. GNU tail’s short `-f` accepts no operand. The long form permits an attached mode. Explicit uutils aliases include `--silent` for head/tail and `-H` for du. The two implementations use different spelling and placeholder conventions. [GNU 9.4 manual source](https://github.com/coreutils/coreutils/blob/v9.4/doc/coreutils.texi) · [GNU tail argument parser](https://github.com/coreutils/coreutils/blob/v9.4/src/tail.c) · [uutils 0.10.0](https://github.com/uutils/coreutils/tree/0.10.0/src/uu)
- **sed, gzip and xz.** A sed backup suffix attaches to the in-place switch, while the script for `-e` consumes a word. Gzip limits the effect of `--ascii` to systems with a text/binary file distinction. XZ documents nine numbered filter-chain declarations and separate optional filter operands. The stored preset range and numeric memory tables remain source context. The default of `--threads` changes from one thread in the Noble capture to automatic CPU-based selection in the Resolute capture. Neither advanced xz options nor GNU-only options are inferred from a different release’s short help. [GNU sed 4.9 source and manual](https://ftp.gnu.org/gnu/sed/sed-4.9.tar.xz) · [GNU gzip 1.14 source and manual](https://ftp.gnu.org/gnu/gzip/gzip-1.14.tar.xz) · [XZ manual](https://tukaani.org/xz/man/xz.1.html)

## Verification boundary

The [utility regression tests](../tests/test_essential_utilities.py) compare every reviewed spelling and its operand count. They check optionality, alias ownership, source sections, build-dependent behavior, wrapped qualifications, and conditional negations. Separate fixed version/argument probes used disposable paths and closed stdin. Ordinary file operations and transfers were outside the checks. The project’s [discovery coverage status](../ROADMAP.md) records the integrated terminal and suite evidence. The three terminal environments replay version-labelled responses, so their Python versions do not imply three separate installations of each utility.
