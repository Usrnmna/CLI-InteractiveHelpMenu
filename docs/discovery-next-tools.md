## Source ownership and user-visible changes

- **GCC.** The complete formatted manual is 1,494,351 bytes and exceeds the 524,288-byte limit. The browser can still use all 37 supported literal rows in root help. The `--help` class selector and `-save-temps` both work bare and accept an equals value. Comma pass-through templates and `-###` cannot be inserted by the literal schema. No truncated flag represents one of those templates.
- **Clang and CMake.** Clang's help aligns descriptions in one column and wraps long option terms onto their own lines. The new reader keeps long terms intact and obtains additional short optimization spellings from the formatted manual. A bare `-Ofast` is documented and deprecated. The two operands in `-Xopenmp-target=<triple> <arg>` have distinct positions. Names containing an embedded template, unsupported punctuation or a comma dispatch prefix stay outside the selectable set. CMake includes the mode selectors and configure flags at the root. The `--parallel` and `--target` definitions under native build mode do not become ordinary configure options. The root menu also stops after `-E`, `--build`, `--install`, `--open` and `--workflow`. Script mode retains its documented `--` separator. [Kitware 4.2.3 mode dispatch](https://raw.githubusercontent.com/Kitware/CMake/v4.2.3/Source/cmakemain.cxx)
- The printed `-L[A][H]` expands into four literal switches and its regex variant into four more. [Compiler readers](../cli_help/compiler_help.py)
- **Go.** Lowercase and quoted operands in Go's tab-indented tables now retain their argument slots. The reader recovers `-o` from the build synopsis and `-exec xprog` from the run synopsis. Module tidy now has six selectable flags, including `-diff`, which prints a diff and exits unsuccessfully if the files would change. The five test-driver definitions remain distinct from a paragraph listing cacheable test flags. The options after `-args` belong to the test binary. [Go and developer-tool reader](../cli_help/developer_help.py)
- **Git.** The stash and worktree pages describe multiple operations. For example, the remove leaf now shows only `-f` and `--force`, with the qualification about repeating the flag for a locked worktree. Stash apply has two quiet spellings and `--index`. Root worktree exposes its eight documented child operations. The stash-list driver has an explicit reflog scope. Graph walks incompatible with the stash reflog and selectors that would replace stash-show's comparison endpoints remain available as source context. The fixed diff request for stash show does not include stash's own manual, so it cannot establish the stash-specific untracked switches. [Reviewed driver](../config/drivers.example/git.json) · [Operation and delegation evidence](git-stash-worktree-manual-coverage.md)
- **.NET and Bun.** The .NET help group starts with `-?`. Its literal syntax remains in Details, and its two supported aliases `-h` and `--help` have selectable rows. In Bun, selecting a debugger or configuration option supports the bare spelling and an optional attached value. The following script remains the child operand.
- **Remaining routes.** The complete tested fixed replies for Cargo, Ninja, pytest, uv, Ruff and modern Yarn matched the audited spellings and operand counts. Detailed manuals, hidden aliases, user plugins, a different release, and test binary help can provide additional declarations. For example Cargo's `--bin [<NAME>]` and `--features <FEATURES>` have different operand requirements. The audit compares what the fixed route returned.
